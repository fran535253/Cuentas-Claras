# Cuentas claras

Aplicación web en español para llevar gastos compartidos, calcular saldos y simplificar pagos entre amigos, compañeros de piso o grupos de viaje.

## Uso

Abre `index.html` en un navegador. No requiere instalación ni cuenta. Los datos se guardan en el almacenamiento local del navegador y se pueden exportar a CSV.

## Publicar en GitHub Pages

1. Sube los archivos de esta carpeta a la raíz de un repositorio de GitHub.
2. En **Settings → Pages**, selecciona **Deploy from a branch** y la rama principal con la carpeta raíz (`/`).
3. GitHub mostrará el enlace público del sitio al terminar la publicación.

La aplicación no tiene servidor ni sincroniza datos entre dispositivos.
